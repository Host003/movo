# 用户端发版前浏览器验收用例

候选版本部署后，由 Codex 在本会话用浏览器逐条操作。每条记录通过、失败或阻塞、会话 ID、截图或 trace、实际结果。阻塞不能算通过。

## 准备

需要候选环境 URL 和版本、同企业普通用户 A 与 B、可正常回答的模型、可持续运行以测试停止的任务、已授权的低风险只读工具，以及对 A 可见的已发布 Skill。准备不含敏感信息的英文翻译样本 `qa/fixtures/release-translation-source.txt`；为每次运行生成唯一的文章验收标记并在 U13、U14 复用。使用隔离账号和无敏感数据。Word/PDF/翻译必须在实际候选部署的浏览器中完成，不用模型文字回复或接口模拟代替文件交付。

## 必跑用例

| 编号 | 浏览器操作 | 通过条件 |
| --- | --- | --- |
| U01 新建会话 | A 登录，点击“新建对话”，发送带唯一标记的任务。 | 新会话、用户消息及完整回答可见；无错误；刷新后能重开。 |
| U02 多轮对话 | 在 U01 会话追问前一轮标记，再发第三轮；切换会话再切回。 | 回答引用正确上下文；消息顺序正确；切换和刷新后不丢失、不重复。 |
| U03 停止对话 | 新会话发送持续运行的任务，运行中点击“停止”，再发送新任务。 | 取消成功、运行结束、输入框恢复；取消后不继续追加旧任务内容；新任务完成。 |
| U04 分享对话 | A 从会话顶部生成分享链接；B 用独立浏览器上下文打开并登录，再回复。 | B 看见历史和作者；B 的回复在 A 页面可见；作者身份正确。 |
| U05 撤销访问 | A 移除 B 或撤销分享；B 刷新并尝试访问旧链接。 | B 不能继续读取或发送；A 的原会话保留。 |
| U06 执行工具 | A 发送必须使用预置只读工具的任务。 | 执行区有对应工具调用及成功状态；回答与工具真实输出一致；刷新后记录仍在。模型自称调用工具不算通过。 |
| U07 执行 Skill | A 在输入框用 `/` 选择指定 Skill，发送任务。 | 已选标签可见；请求携带 `selected_skill_id`；执行或结果符合 Skill 预期；刷新后可回看。 |
| U08 会话隔离 | 连续新建两个会话，分别发任务并来回切换。 | 会话 ID、历史和回复不串；标题及排序可识别。 |
| U13 文章生成并导出 Word | 新建会话，发送：“写一篇约 300 字的中文文章，题为《发版验收报告》，包含本次唯一验收标记、一级标题、两个小节和结论；生成可下载的 Word 文件，文件名为 `movo-release-article.docx`。”等待任务结束，查看回答下方产物卡片，点击下载并打开文件；刷新后重开会话。 | 回答中的文章满足结构与标记；**页面出现对应 `.docx` 下载卡片**，按钮可点击；实际下载为可打开的 DOCX，正文含标记、标题和结论；刷新后卡片仍在且可再次下载。仅回答“已生成”不算通过。 |
| U14 文章导出 PDF | 在 U13 会话继续要求：“将刚才的文章另导出为 PDF，文件名为 `movo-release-article.pdf`，保留标题、小节、结论和验收标记。”等待完成，检查新产物卡片、下载并打开 PDF；刷新后重开。 | **页面出现对应 `.pdf` 下载卡片**；文件能打开且有可读正文，标题、结论及标记与 Word 版本一致，中文没有乱码或空白页；刷新后仍可下载。Word 卡片不能代替 PDF 卡片。 |
| U15 文档翻译与交付 | 新建会话，上传 `qa/fixtures/release-translation-source.txt`，明确要求翻译成中文、保留标题、两条要点、表格中的数字 `73421` 和术语 `MOVO`，并导出 `movo-release-translation.docx`。等待任务结束，查看译文和下载卡片，下载并打开；刷新后重开。 | 译文语义正确、结构完整，数字 `73421` 和术语 `MOVO` 未被改写；**页面出现译文 `.docx` 下载卡片**，下载文件可打开且内容与译文对应；刷新后卡片与附件引用仍在。只输出译文文本不算交付通过。 |

## 按启用能力补跑

| 编号 | 条件与通过标准 |
| --- | --- |
| U09 文件 | 启用文件能力时上传固定样本，核对附件状态、读取和来源；不支持格式须明确报错。产物交付由 U13–U15 分别验收。 |
| U10 知识库 | 启用知识库时用固定知识样本提问，核对检索证据和回答。 |
| U11 定时任务 | 启用定时任务时创建短周期测试任务，确认触发、会话和结果，然后删除测试任务。 |
| U12 桌面能力 | 若随版发布 Code 或浏览器 Agent，在对应桌面客户端核对权限、执行记录和结果。 |

## 发版结论

U01–U08、U13–U15 全部通过，且本次启用的 U09–U12 全部通过，才能报告“用户端浏览器验收通过”。Word、PDF 或翻译任一交付缺少下载卡片、下载失败、文件打不开、内容不符，都记失败；无法运行则记阻塞，不能算通过。报告需列候选版本、环境、日期、每条用例的状态、会话 ID、卡片截图、下载文件名及内容核验结果。缺第二账号、工具、Skill 或慢任务环境时，先补齐再执行，不能省略必跑项。

`qa/release-smoke.spec.ts` 自动覆盖 U01 和 U02 的主要路径；现有 `qa/session-sharing-realtime.spec.ts` 是分享专项 QA 测试。U13–U15 目前由 Codex 浏览器逐条执行并核验下载文件，尚无独立自动化。完整门禁以 Codex 浏览器逐条执行本清单为准。
